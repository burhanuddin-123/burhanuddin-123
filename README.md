## Featured projects

### DevOps & CI/CD
- **[etl-gitops-app](https://github.com/burhanuddin-123/etl-gitops-app)** + **[etl-gitops-config](https://github.com/burhanuddin-123/etl-gitops-config)**: a full GitOps loop. CI tests the code, builds an image tagged with the commit SHA, pushes it to a registry and commits the new tag to a config repo that Argo CD deploys from.
- **[databricks-etl-ci-cd](https://github.com/burhanuddin-123/databricks-etl-ci-cd)**: a test-gated GitHub Actions pipeline that deploys an ETL job to Databricks.
- **[kind-local-ci-cd](https://github.com/burhanuddin-123/kind-local-ci-cd)**: zero-cost CI/CD with a self-hosted runner deploying to a local kind cluster.

### Cloud & full-stack
- **[aws-console-clone](https://github.com/burhanuddin-123/aws-console-clone)**: a React clone of the AWS console that runs against a local AWS emulator, so you can practise S3, DynamoDB, EC2, Lambda and CloudWatch at zero cost.
- **[slidevault](https://github.com/burhanuddin-123/slidevault)**: MERN platform to author, upload and share HTML presentations, with JWT auth and S3 storage.
